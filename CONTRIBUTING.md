# Contributing

Thank you for contributing to OpenClaw Optimization Agent.

## Workflow
1. Fork the repository and create a feature branch.
2. Keep changes focused and small.
3. Include clear motivation and expected impact in your PR.
4. Link related issue numbers when possible.

## Pull Request Checklist
- Explain why this change is needed.
- Describe performance impact and risk.
- Provide reproduction or validation steps.
- Keep docs updated if behavior changes.

## Commit Style
Use concise commit messages, for example:
- feat: add scenario scheduling policy
- fix: reduce memory overhead in metrics collector
- docs: refine optimization workflow

## Code of Conduct
By participating, you agree to follow CODE_OF_CONDUCT.md.
